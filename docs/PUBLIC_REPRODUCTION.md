# Public reproduction boundary

Four owner-approved artifacts enable trained inference, representative landmark replay, RGB-to-MediaPipe smoke and sample-only controller comparison. Calibration is loaded by the preserved runtime and ROM comparator. The sample uses nominal12FPS export; its matching control landmarks retain original timestamps and pre-crop image coordinates. Redacted-sample coverage is a smoke measurement, not the original dataset coverage.

Five held-out clips, their manifest, teacher reference and provenance remain private. Full published comparisons are inspectable as archived results but cannot be recomputed from one sample. Full retraining requires the original34 private recordings. Historical larger release manifests do not grant publication consent. Missing input fails explicitly.

The successful attended neural run used the existing any-hand option with one visible hand; strict handedness can reject detections. Camera/display/export FPS and software/physical latency must be distinguished. Tests in this preparation reuse the installed Python3.11.9 environment and verified local assets; new wheel/network installation was not repeated.

Public dataset-audit hashes are deterministic group pseudonyms; original source-video hashes remain private. They demonstrate split grouping, not file-integrity provenance.

The owner-provided Google Drive demonstration is linked from the main README and was opened and played in a signed-out browser session. The video includes the operator visibly in some camera segments. The README still is taken from a separate masked hand pane in the same demonstration; masking the still does not anonymize the full video.
